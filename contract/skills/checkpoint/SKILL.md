# Checkpoint save

Per the project's own `HANDOFF-PROCESS.md` ("Checkpoint saves" — the project's copy
governs): HANDOFF.md is only ever revised. The delta pass updates, in place:

- the TL;DR / current state,
- the live thread,
- session-so-far themes,
- anything newly easy to get wrong.

Checkpoint deltas do NOT archive — only full handoff rewrites do. Five minutes, not a
ceremony.

If the project has no `HANDOFF.md`, it hasn't adopted the contract — offer
`/build-contract:adopt` or `/build-contract:setup` instead.

If the reason for this checkpoint is that the context window is at roughly 70–80%, a
checkpoint is the wrong tool: escalate to `/build-contract:handoff` and begin the FULL
handoff now — the final 20% is for finishing it, not starting it.
